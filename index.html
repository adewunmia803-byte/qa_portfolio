02
BUG INVESTIGATION · CROSS-PLATFORM

Store Listing & Visibility

Investigated a store that appeared in a support interface but was not visible in the customer mobile application after onboarding and operating-hours setup.

Cross-platformData consistencyFeature validation

Investigation path

  1. Create a store and complete onboarding.
  2. Configure operating hours.
  3. Check its presence in the support interface.
  4. Compare visibility in the customer application.
  5. Capture evidence and report the observed difference.

The observed behaviour is presented as an investigation; root cause and resolution are not claimed here.

RISK INVESTIGATION · STAGING

Recharge Transaction Workflow

Raised a question about environment separation after a recharge-card purchase attempt in staging appeared to proceed using a phone number.

Payment workflowEnvironment validationIntegration risk

QA considerations

  • Confirm the target environment and provider configuration.
  • Verify transaction status using approved test evidence.
  • Check whether staging uses sandbox credentials and test endpoints.
  • Escalate any possibility of live financial impact.

This is documented as a potential environment/configuration risk, not a confirmed live transaction.
