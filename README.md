# Adewunmi Adenuga — QA Portfolio

Responsive light-theme portfolio built with HTML, CSS and vanilla JavaScript.

## Preview
Open `index.html` in a browser.

## Deploy free with GitHub Pages
1. Create a public repository on GitHub, e.g. `qa-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub will publish a URL for the website.
